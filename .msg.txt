fix(config): a typo in astra.yaml disabled the whole tool

config.py measured 56% covered. The uncovered half was _simple_yaml — the
parser used when pyyaml is absent — plus two defects that made any problem
with the settings file fatal.

A malformed or unreadable astra.yaml raised out of Config(). Since Config is
constructed on paths that index a repository, one stray tab in the settings
file meant no repository could be indexed at all. An unreadable file — locked
by an editor, or an antivirus filter holding it — did the same. Both now fall
back to the defaults, which are a working configuration.

raw returned dict(self._raw), a shallow copy. The nested sections were still
shared, so config.raw["scanner"]["worker_count"] = 99 changed what
config.get("scanner.worker_count") returned: a property that looks like a read
and edits the settings. It is a deep copy now.

The tests also pin what _simple_yaml gets wrong rather than leaving it
undocumented: a YAML list becomes an empty mapping, and an inline list stays a
string. pyyaml is a hard dependency so this only runs on a partial install,
but it fails silently rather than loudly, which is the worse shape. A test
compares the fallback against pyyaml on the same file so the two cannot drift
apart unnoticed.

Each fix was removed and confirmed to fail a test; the first attempt at the
unreadable-file case passed with the fix reverted, which is what turned up
that it had no test at all.

396 -> 397 tests. All gates clean.
